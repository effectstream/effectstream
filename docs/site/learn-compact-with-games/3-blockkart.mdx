A fast-paced racing simulator where you compete for the top spot. Combining Midnight with Arbitrum finality to build a snappy racing loop with an onchain leaderboard.

## Technical challenges

### Arbitrum for faster finality

We settle on Arbitrum to shorten the gap between input and confirmed
result. We compare what the racing loop felt like before and after the
switch.

### Effect stream usage

The contract emits a stream of effects the client consumes as they land.
This section walks through how the client renders optimistically, how it
reconciles when the stream catches up, and what happens when they
disagree.

### A simple leaderboard

Once finality is fast enough, the leaderboard mostly takes care of
itself - every finished race writes a result and the board reads from
that. We cover the schema and the few edge cases that still need care
(disconnects, ties, replays).

## Source & Compact code

<GameRepo />

**Source:** [`packages/shared/contracts/midnight-contracts/contract-midnight-data/src/midnight-data.compact`](https://github.com/effectstream/block-kart-legends/blob/main/packages/shared/contracts/midnight-contracts/contract-midnight-data/src/midnight-data.compact)

BlockKart is a racing game settled almost entirely on Arbitrum for snappy finality. The Midnight contract is intentionally tiny - it stores one opaque payload string and exposes one circuit to write it. This is the teaching moment: not every Compact contract should model the whole game.

### The "anchor only" pattern

The entire contract is 11 lines: a single `ledger payload: Opaque<"string">` plus a `storeValue` circuit that `disclose`s and writes it. There are no enums, no maps, no witnesses, no commit-reveal. All of BlockKart's race state (lap times, collisions, leaderboard math) lives in the Arbitrum contract; Midnight here is the immutable notarization step. Use this pattern when you need tamper-evident anchoring but not zero-knowledge - the cheaper the on-chain piece, the cheaper every state update.

<CompactCode summary="Full contract (11 lines)">

```compact
pragma language_version >= 0.18.0;

import CompactStandardLibrary;

constructor() {
}

export ledger payload: Opaque<"string">;

export circuit storeValue(_payload: Opaque<"string">): [] {
    payload = disclose(_payload);
}
```
