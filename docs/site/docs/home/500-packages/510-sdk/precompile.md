> Package: **[`@effectstream/precompile`](https://www.npmjs.com/package/@effectstream/precompile)** · [Source](https://github.com/PaimaStudios/paima-engine/tree/main/packages/effectstream-sdk/precompile)

Generate deterministic EVM-sized (20-byte) addresses from string names. Used
inside EffectStream to register "precompiles" — synthetic addresses that the
state machine reserves for non-user logic like primitives, timers, and
internal events.

## Install

```bash
bun add @effectstream/precompile
# or
npm install @effectstream/precompile
```

## Standalone usage

Pure function. Given a name, get an address. Same name, same address —
always.

```typescript
import { generatePrecompile, generatePrecompiles } from "@effectstream/precompile";

const addr = generatePrecompile("MY_FEATURE");
// addr === "0x<first-20-bytes-of-keccak256-of-MY_FEATURE>"

// Bulk-derive a typed map from a string enum.
enum MyNames {
  A = "feature-a",
  B = "feature-b",
}
const map = generatePrecompiles(MyNames);
// map["feature-a"] === generatePrecompile("feature-a")
// map["feature-b"] === generatePrecompile("feature-b")
```

The result is an EVM-shaped `0x[40 hex chars]` string, so you can use it
anywhere viem/ethers expects an `Address`.

## Inside EffectStream

`generatePrecompiles` is how every package that ships intrinsic
primitives, timers, or internal accounts registers a stable address
without colliding with user contracts. Names are stable across versions,
so an address generated today will match an address generated by a future
build of the same name.

## Key exports

- `generatePrecompile(name: string): HexString0x` — `0x` + first 40 hex chars of `keccak256(name)`.
- `generatePrecompiles(names: Record<string, string>)` — bulk variant. Returns `{ [value]: address }` so consumers can use values as keys.
